# 관계 기록 (relation-record)

6대 영역 중 「관계」 기록 앱(2026-11-11 시작, 시험판). 지금은 **통화만**: 어떤 전화 앱(익시오 등)으로 통화해도 폰 통화 기록(걸었나/받았나·시각·통화 시간)을 읽어 사람별로 쌓는다. 녹음·통화 내용은 읽지도 올리지도 않는다.

- **구조 원칙(2026-11-11 룡): 통화가 우선. 메인 수집 = 통화에서 들어오는 것**(통화 끝 작은 창·알림). 「+ 사람」 직접 넣기는 보조.
- **기록 기준(2026-11-13 룡)**: 기록할 사람 = **다시 연락할 사람**(택배·배달·광고·한 번 묻고 끝난 곳은 [아님]). 영역 = **무슨 일로 통화했나**, 일이 아니면 「개인」(일반 친분: 친구·가족), 사역 일이면 「사역」. 창에는 「개인」이 미리 골라져 있어 모르겠으면 [저장]만, 일 영역을 누르면 그 영역으로 바뀐다. 영역은 나중에 사람 화면에서 바꾼다.
- 등록된 사람 번호 → 묻지 않고 기록. 처음 번호는 통화가 끝나면 화면 아래 **작은 창**(이름·영역 고르고 [저장] / [아님], 「다른 앱 위에 표시」 켰을 때)으로 바로 묻고, 알림도 함께 남는다(2026-11-11 룡 「팝업, 바로 저장」). 처음 번호(실제로 통화한 것) → 알림 「기록할 사람인가요?」 [기록] [아님]. 답할 때까지 알림이 남고, 앱 첫 화면 맨 위에도 뜬다. [아님] → 제외 번호(다시 안 물음).
- 제외 번호·답 안 한 번호는 **폰 안에만**(서버에 안 올림). 연락처에 있는 사람도 다 묻는다(2026-11-11 룡: 「연락처 모두 제외」 물음 없앰). 제외는 알림 [아님] 또는 ⚙ 설정 「제외 번호」에서 번호 더하기.
- 로그인 = 업무 기록 아이디·비밀번호(재정 기록과 같은 방식, `rel_login`). 열쇠는 폰에 저장, 365일.
- 보이는 범위 = **기록 한 줄마다 영역**: 「개인」(교회·친구·가족) 기록은 쓴 사람만, 일 영역 기록은 업무 기록에서 그 영역을 볼 수 있는 사람. 사람 카드는 영역을 여러 개 가질 수 있고, 첫 영역에 통화가 들어간다.
- **영역 = 업무 기록 구성원이 가진 영역 그대로**(`work_members.visible_companies`, 오레진 포함. 2026-11-13 룡, 아내 OK) + 사람마다 **나만 보는 칸**(`rel_my_areas`, 룡: 「사역」 = 재정캠프·정착배가 등). 나만 보는 칸은 「개인」처럼 쓴 사람만 본다. 새 칸은 `rel_my_areas`에 한 줄 더한다.
- **녹음 글 붙이기(2026-11-13 룡)**: 사람 화면의 내 통화 줄 [📋 녹음 글 붙이기] → 삼성 녹음 앱에서 복사한 글을 붙여 저장 → `rel_add_transcript`가 업무 기록 「노트」(`work_notes`: 제목 `YYMMDD 통화 HH:MM 이름`, 종류 노트, 작성중, 적은 사람 = 본인, 영역 = 통화 영역·나만 보는 칸이면 비움, 본문 `## 🎙 전사본`)로 넣고 통화 줄에 `note_id`를 단다. 다시 붙이면 작성중일 때만 바꾼다. 정리는 하루 마무리가 노트에서 가져간다. 일레븐랩스(돈)는 안 쓴다.
- 서버: 슈파베이스 「룡룡룡」 `rel_people`·`rel_records`·`rel_sessions`. 표는 잠김(RLS, 정책 없음, anon·authenticated 권한 없음), 폰은 `rel_` 함수로만.
- 화면: `android/app/src/main/assets/index.html`(WebView). 서버 부르기는 `Native.rpc`(자바)로만.
- 빌드: GitHub Actions → `app/relation-record.apk` + `app/version.json`(앱이 보고 스스로 업데이트). 서명은 기록 앱 공용 열쇠 `record`.
